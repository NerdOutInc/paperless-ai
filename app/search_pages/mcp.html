Claude Code

Run this from a terminal. Keep the header exactly as shown for HTTP or HTTPS installs. 

claude mcp add --transport http {{SERVER_NAME}} {{MCP_URL}} \
  --header "Authorization: Bearer {{MCP_TOKEN}}"

claude mcp list
Claude Desktop

Open Claude Desktop, choose Claude > Settings > Developer > Edit Config, then add this server. Keep --allow-http for local HTTP installs; remove it for HTTPS. 

{
  "mcpServers": {
    "{{SERVER_NAME}}": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "{{MCP_URL}}",
        "--allow-http",
        "--header",
        "Authorization: Bearer {{MCP_TOKEN}}"
      ],
      "env": {
        "PATH": "YOUR_NODE_BIN_DIR:/usr/local/bin:/opt/homebrew/bin:/usr/bin:/bin"
      }
    }
  }
}
Codex CLI and Codex Desktop

Add the HTTP MCP server with the CLI, then restart Codex Desktop or open a fresh Codex CLI session so it reloads the MCP config. 

export PAPERLESS_AG_MCP_TOKEN="{{MCP_TOKEN}}"
codex mcp add {{SERVER_NAME}} \
  --url {{MCP_URL}} \
  --bearer-token-env-var PAPERLESS_AG_MCP_TOKEN

codex mcp list
VS Code with GitHub Copilot

Add this to your workspace's .vscode/mcp.json, then use Copilot Chat's MCP server list or agent mode to enable it. 

{
  "servers": {
    "{{SERVER_NAME}}": {
      "type": "http",
      "url": "{{MCP_URL}}",
      "headers": {
        "Authorization": "Bearer {{MCP_TOKEN}}"
      }
    }
  }
}
llama.cpp built-in web UI

Use a recent llama-server build and start it with the MCP proxy enabled. New builds use --ui-mcp-proxy; older builds may still accept --webui-mcp-proxy. Keep that proxy on a trusted local network. 

llama-server -m /path/to/model.gguf --jinja --ui-mcp-proxy
  1. Open the llama.cpp web UI in your browser.
  2. Open the MCP servers/settings screen and add a server.
  3. Set the server name to paperless-ag.
  4. Set the server URL to Loading....
  5. Add a custom header named Authorization with the value Loading....
  6. Turn on Use llama-server proxy, save the server, and run the health check.

If llama-server runs inside Docker, the URL must be reachable from that container. In the older Paperless Ag local AI branch, this was wired as http://caddy:8088/mcp with proxying enabled and Caddy injecting the token internally.
