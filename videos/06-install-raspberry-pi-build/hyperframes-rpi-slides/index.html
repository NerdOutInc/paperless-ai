why a Raspberry Pi
A quiet little server for a modest local archive.
Use Raspberry Pi OS Lite, keep it on the network, and prefer a USB SSD when the archive becomes real work.
Pi 4/5
Local by default No public server required for the home-network setup.
Low power Practical for a small farm or ranch document archive.
SSH managed Headless install, no monitor or desktop environment.
SSD preferred Better long-term fit for Postgres, OCR, and uploads.
