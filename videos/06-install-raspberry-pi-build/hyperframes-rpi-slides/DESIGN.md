# Fullstack AG Raspberry Pi Install Slides Design

## Style Prompt

Warm technical explainer for agricultural operators. The Raspberry Pi slides
should match the prior VPS and Docker HyperFrames segments and the current
Fullstack AG website: practical, calm, local-first, and grounded. Use a dark
field-inspired canvas, cream type, sage infrastructure details, burnt-orange
emphasis, subtle dot and field-line texture, terminal labels, and short copy
that supports the narration instead of competing with it.

## Colors

- `#17120f` charcoal: dark canvas, terminal surfaces, deep UI chrome
- `#5f7358` sage: local network, infrastructure accents, field texture
- `#f5f1eb` cream: primary text and light panels
- `#d4622b` burnt orange: section badges, status marks, active strokes
- `#3f2f27` chocolate: secondary panels and warm shadow depth

## Typography

- Manrope: headings, section labels, big operator-facing claims
- Inter: supporting copy and concise explanatory text
- JetBrains Mono: hostnames, URLs, setup labels, and technical readouts

## Motion Rules

- Keep the title card stable for about three seconds before the first fade.
- Use slow field-line drift and subtle grain so the slides feel alive but not
  flashy.
- Use entrance animations for every explanatory scene element.
- Use warm wash transitions between slide scenes.
- Keep copy readable at a glance; this narration carries the detail.

## What NOT to Do

- Do not use generic blue or purple technology gradients.
- Do not turn this into public-cloud or SaaS marketing.
- Do not add a dense Raspberry Pi administration lesson.
- Do not read, expose, or stylize the MCP token.
- Do not overwrite the existing source video or narration audio.
